# Foody – Food Website

Foody is a simple food website where users can explore different food items like Pizza, Burgers, Momos and Fries.

### Features
- Search food items
- Browse food categories
- Add items to cart
- View cart total
- Responsive design

### Technologies Used
- HTML
- CSS
- Bootstrap
- JavaScript
